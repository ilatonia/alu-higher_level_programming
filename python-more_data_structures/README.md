# python-more_data_structures

This project covers more data structure operations in Python: list comprehensions, sets, and working with 2D lists without modifying the original data.

## Tasks

| File | Description |
| --- | --- |
| `0-square_matrix_simple.py` | Returns a new matrix with the square of every value of the input matrix |
| `1-search_replace.py` | Returns a new list with all occurrences of an element replaced by another |
| `2-uniq_add.py` | Adds all unique integers in a list (once per integer) |
| `3-common_elements.py` | Returns a set of the elements common to two sets |

## Requirements

- Python 3, interpreted on Ubuntu
- All files start with `#!/usr/bin/python3`, end with a new line, and are executable
- Code follows the PEP 8 style (`pycodestyle`)
- No module imports are allowed
