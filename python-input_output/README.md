# Python - Input/Output

This project covers reading and writing files with the `with` statement,
JSON serialization and deserialization, turning objects into dictionaries,
and a Pascal's triangle exercise.

## Files

| File | Description |
|------|-------------|
| `0-read_file.py` | Reads a UTF8 text file and prints it |
| `1-write_file.py` | Writes a string to a file and returns the characters written |
| `2-append_write.py` | Appends a string to a file and returns the characters added |
| `3-to_json_string.py` | Returns the JSON string of an object |
| `4-from_json_string.py` | Returns the object represented by a JSON string |
| `5-save_to_json_file.py` | Saves an object to a file as JSON |
| `6-load_from_json_file.py` | Creates an object from a JSON file |
| `7-add_item.py` | Script that loads, extends and saves `add_item.json` |
| `8-class_to_json.py` | Returns the dictionary description of an object |
| `9-student.py` | `Student` class with `to_json` |
| `10-student.py` | `Student` with `to_json` filtered by attribute names |
| `11-student.py` | `Student` with `to_json` and `reload_from_json` |
| `12-pascal_triangle.py` | Returns the Pascal's triangle of `n` |
