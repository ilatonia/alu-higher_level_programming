# Python - Everything is object

This project covers how Python treats everything as an object: `id` and `type`, mutable vs immutable objects, aliasing, how integers and strings are cached, and how arguments are passed to functions.

## Files

| File | Description |
|------|-------------|
| `0-answer.txt` to `18-answer.txt` | Answers to the conceptual questions about `type`, `id`, `==` vs `is`, lists, and function arguments |
| `19-copy_list.py` | Function that returns a copy of a list |
| `20-answer.txt` to `28-answer.txt` | Answers about tuples, identity, and list `+` vs `+=` |
