The ``3-say_my_name`` module
============================

Using ``say_my_name``
---------------------

Import the function:

    >>> say_my_name = __import__('3-say_my_name').say_my_name

Printing a first and a last name:

    >>> say_my_name("John", "Smith")
    My name is John Smith
    >>> say_my_name("Walter", "White")
    My name is Walter White

The last name is optional. A trailing space is printed in that case, so the
exact output is captured to show it:

    >>> import contextlib
    >>> import io
    >>> output = io.StringIO()
    >>> with contextlib.redirect_stdout(output):
    ...     say_my_name("Bob")
    >>> output.getvalue()
    'My name is Bob \n'
    >>> output.getvalue() == "My name is Bob \n"
    True

Names with spaces, accents or digits are plain strings:

    >>> say_my_name("Mary Ann", "O'Neil")
    My name is Mary Ann O'Neil
    >>> say_my_name("Zoë", "Muñoz")
    My name is Zoë Muñoz
    >>> say_my_name("R2", "D2")
    My name is R2 D2

The first name must be a string:

    >>> say_my_name(12, "White")
    Traceback (most recent call last):
    TypeError: first_name must be a string
    >>> say_my_name(None)

    >>> say_my_name(["John"], "Smith")

The last name must be a string:

    >>> say_my_name("John", 12)
    Traceback (most recent call last):
    TypeError: last_name must be a string
    >>> say_my_name("Bob", None)
    Traceback (most recent call last):

    >>> say_my_name("Bob", ("Smith",))

    >>> say_my_name(12, 12)
    Traceback (most recent call last):
