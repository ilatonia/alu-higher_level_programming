The ``2-matrix_divided`` module
===============================

Using ``matrix_divided``
------------------------

Import the function:

    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

Dividing a matrix of integers:

    >>> matrix = [
    ...     [1, 2, 3],
    ...     [4, 5, 6]
    ... ]
    >>> matrix_divided(matrix, 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

The original matrix is left untouched:

    >>> matrix
    [[1, 2, 3], [4, 5, 6]]

Dividing a matrix of floats, or of integers and floats:

    >>> matrix_divided([[1.5, 2.5]], 2)
    [[0.75, 1.25]]
    >>> matrix_divided([[1, 2.5], [3, 4.5]], 2)
    [[0.5, 1.25], [1.5, 2.25]]

The division can be done by a float or a negative number:

    >>> matrix_divided([[1, 2], [3, 4]], 2.5)
    [[0.4, 0.8], [1.2, 1.6]]
    >>> matrix_divided([[1, -2]], -2)
    [[-0.5, 1.0]]

Results are rounded to 2 decimal places:

    >>> matrix_divided([[10, 2]], 3)
    [[3.33, 0.67]]

A matrix with a single element or a single row works too:

    >>> matrix_divided([[8]], 2)
    [[4.0]]
    >>> matrix_divided([[1, 2, 3]], 1)
    [[1.0, 2.0, 3.0]]

Dividing by infinity gives zeros:

    >>> matrix_divided([[1, 2], [3, 4]], float('inf'))
    [[0.0, 0.0], [0.0, 0.0]]
