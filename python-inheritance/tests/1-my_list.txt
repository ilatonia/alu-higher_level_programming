===========================
How to Use 1-my_list.py
===========================

This module defines a class ``MyList`` that inherits from ``list`` and adds
a ``print_sorted`` method.

Usage
=====

``MyList`` behaves like a list. ``print_sorted()`` prints the elements in
ascending order without changing the list itself.

::

    >>> MyList = __import__('1-my_list').MyList
    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

It is a real list subclass:

::

    >>> isinstance(my_list, list)
    True

An empty list:

::

    >>> empty = MyList()
    >>> empty.print_sorted()
    []

Negative numbers and duplicates:

::

    >>> mixed = MyList([3, -1, 3, 0, -7])
    >>> mixed.print_sorted()
    [-7, -1, 0, 3, 3]
    >>> print(mixed)
    [3, -1, 3, 0, -7]

An already sorted list:

::

    >>> ordered = MyList([1, 2, 3])
    >>> ordered.print_sorted()
    [1, 2, 3]

A reverse sorted list:

::

    >>> backwards = MyList([3, 2, 1])
    >>> backwards.print_sorted()
    [1, 2, 3]
    >>> print(backwards)
    [3, 2, 1]
