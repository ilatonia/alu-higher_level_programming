# python-exceptions

Python exercises on handling exceptions with `try` / `except` / `finally`.

## Files

| File | Description |
| --- | --- |
| `0-safe_print_list.py` | `safe_print_list(my_list=[], x=0)` prints `x` elements of a list and returns the number actually printed. |
| `1-safe_print_integer.py` | `safe_print_integer(value)` prints an integer with `"{:d}".format()` and returns `True`, or `False` if `value` is not an integer. |
| `2-safe_print_list_integers.py` | `safe_print_list_integers(my_list=[], x=0)` prints only the integers among the first `x` elements and returns how many were printed. |
| `3-safe_print_division.py` | `safe_print_division(a, b)` divides two integers, prints the result in the `finally:` block, and returns it (or `None`). |
| `4-list_division.py` | `list_division(my_list_1, my_list_2, list_length)` divides two lists element by element and returns a new list. |
| `5-raise_exception.py` | `raise_exception()` raises a `TypeError`. |
| `6-raise_exception_msg.py` | `raise_exception_msg(message="")` raises a `NameError` with the given message. |

## Requirements

- Python 3, with files starting with `#!/usr/bin/python3`
- No modules may be imported
- Code follows the PEP 8 style (`pycodestyle`)
